# photo-collage

Альбомоагностичный шаблон фотоколлажа для телевизора и телефона.
Кладёте фото фотосессии в папку — запускаете одну команду — получаете
готовую страницу-коллаж: адаптивные раскладки под портрет и альбом,
навигация пультом, свайпы, PWA-установка на телефон.

Без сборочных фреймворков: страница — чистый ES5-JavaScript (работает
в старых Android WebView ~2014 года), сборка — один Node-скрипт.

## Быстрый старт

```sh
# 1. положить фото фотосессии в photos-src/ (jpg/png, любые размеры)
# 2. установить зависимости и собрать + поднять локальный показ:
npm install
npm start          # сборка + сервер на http://localhost:8080
```

Откройте `http://localhost:8080` на ТВ/телефоне/компьютере.
В репозитории лежит несколько демо-фото — удалите их и положите свои.

Что делает `npm start`:

1. `npm run build` — из `photos-src/` создаются `photos_mid/`
   (полные копии ~1600px), `photos_thumb/` (миниатюры ~400px)
   и `config.js` — карта фото с ориентацией и отношением сторон
   (`o: 'p'/'l'`, `r: w/h`). Повторный запуск обновляет только
   изменившиеся файлы.
2. `npm run serve` — статический сервер на порту 8080.

## Публикация

Результат — статические файлы. Положите содержимое проекта на любой
статический хостинг или в любую папку домашнего сервера: страница
не требует бэкенда. Не забудьте закоммитить/выложить сгенерированные
`photos_mid/`, `photos_thumb/`, `config.js` и `version.js`
(в этом шаблоне они в `.gitignore` — для публикации скопируйте их
в место раздачи вместе с `index.html`, `app.js`, `manifest.json`
и иконками).

## Раскладки

| Режим | Что на экране |
|---|---|
| **1 «змейка»** | слева эскизы-ссылки на соседние страницы и счётчик; центр — портретное фото; справа фото 4:3 и панель: номер страницы, кнопки [−][+] и пауза |
| **2** | один экран = портрет во всю высоту (ширина от пропорции кадра, без обрезки) + две альбомные стопкой справа |
| **3** | два столбца: экран из двух портретов или из двух стопок альбомных — чего в остатке больше, то и на экране |
| **4** | каждое фото на весь экран, вписано целиком (`contain`), без обрезки |

Раскладки 2–4 — длинная лента всех фото: прокрутка колесом мыши,
«курсором» с пульта (стрелки двигают рамку, OK открывает страницу
«змейки» с этим фото), Esc — свободная прокрутка. Отступы и
закругления зависят от высоты экрана: тонкие на телефоне, крупные на ТВ.

Фото разбиваются на портретный и альбомный пулы; страница «змейки»
берёт по одному из каждого — дублей на экране не бывает.

## Управление

**ТВ/пульт (и клавиатура):** стрелки — фокус по элементам / страницы,
OK/Enter — нажать, 1–4 — раскладки, P или пробел — пауза, M — следующий
плейлист, Esc/Back — снять фокус / вернуть меню.

**Телефон:** свайп влево/вправо — страницы, одиночный тап по фото —
меню раскладок (прозрачные круглые кнопки на правом краю), двойной тап —
системное поведение, меню раскладок также прячет тап по эскизу навигации.
По первому тапу страница просит полноэкранный режим и лочит альбомную
ориентацию; в портрете показывается заставка «поверните устройство»
(с кнопкой «смотреть как есть»).

**Установка как приложение:** манифест PWA — «Добавить на главный экран»
открывает коллаж без интерфейса браузера.

## Настройка

- `options.intervalSec` в `config.js` — скорость автолистания «змейки»;
- `options.fadeSec` — длительность переходов;
- `options.scenario` — автосценарий, например:

```js
scenario: [
  { delay: 60, action: 'setLayout', args: ['snake'] },
  { delay: 30, action: 'setLayout', args: ['grid2x2'] }
]
```

- несколько плейлистов — добавьте второй массив в `playlists`;
- JS API для своих сценариев: `Collage.nextPage() / prevPage() /
  setPage(n) / setLayout(name) / pause() / resume() / playScenario([...])`.

## Обновления

Открытая страница раз в 5 минут сверяет `version.js`; после публикации
новой сборки у зрителей появится тост «Вышло обновление → Обновить».

## Структура

```
photos-src/     ваши фото (источник)
photos_mid/     генерируется: полные копии ~1600px
photos_thumb/   генерируется: миниатюры ~400px
scripts/build.js  сборка (Node, без внешних зависимостей кроме jimp)
index.html      разметка и стили
app.js          движок коллажа (ES5)
config.js       генерируется: карта фото и настройки
manifest.json   PWA-манифест
```

## Развитие

Всё, что касается тюнинга раскладок (компоновка режимов, пропорции
колонок, отступы, ленивая загрузка), ведётся в ветке
[`layout-tuning`](https://github.com/dudkoalex/photo-collage/tree/layout-tuning) —
там же живёт план экспериментов: [docs/TUNING.md](docs/TUNING.md).
Ветка `main` — стабильный шаблон: сюда попадает только проверенное.
