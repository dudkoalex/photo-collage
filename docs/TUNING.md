# Тюнинг раскладок — открытые вопросы

**Намерение:** все доработки компоновки раскладок ведутся в этой ветке
(`layout-tuning`) и только здесь; `main` принимает проверенные
результаты через merge. План ниже — очередь экспериментов.

## Кандидаты на эксперименты

- **Режим 2**: ширина правой стопки сейчас от средней пропорции
  альбомного пула — попробовать подбирать под каждое фото отдельно
  (рваная колонка vs предсказуемая).
- **Режим 3**: чередование «портретный экран / альбомный экран»
  сейчас по балансу пулов; попробовать строгое чередование или
  группировку по 2.
- **Змейка**: соотношение колонок (14/32/54) и высота панели
  статистики (22%) — снять в живую с разных расстояний до ТВ.
- **Гэпы**: формула 5/14/24px по высоте вьюпорта — проверить
  на промежуточных высотах (планшеты ~600–800px).
- **Ленивая загрузка**: окно «2 экрана вперёд» и очередь из 2
  параллельных предзагрузок — померить на медленном 3G.

## Как пробовать

Правки — только в `app.js` (функции `buildSnake`, `buildTapeMode2`,
`buildTapeMode3`, `gridMetrics`). Проверка: `npm start`, режимы
переключаются клавишами 1–4.
